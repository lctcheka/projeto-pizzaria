# 🍕 Projeto Pizzaria

Uma aplicação web completa e responsiva concebida para a gestão e realização de pedidos online de uma pizzaria. O sistema inclui fluxos para o cliente final (seleção de produtos, carrinho e acompanhamento do pedido) e uma interface administrativa para gestão.

---

## 🚀 Funcionalidades

- ** Navegação & Menu Interativo:** Apresentação do catálogo de pizzas e acompanhamentos com interface intuitiva.
- ** Acompanhamento em Tempo Real (`acompanhar.html`):** Painel dedicado para o cliente verificar o estado da sua encomenda.
- ** Painel de Administração (`admin.html`):** Interface para gestão interna dos pedidos e operações da pizzaria.
- ** Páginas Institucionais:** Secções integradas de Termos de Serviço (`termos.html`) e Política de Privacidade (`privacidade.html`).

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript (ES6+)
- **Estilização:** CSS Modular (`styles.css` para a aplicação e `legal.css` para páginas institucionais)
- **Lógica & Dinamismo:** JavaScript nativo (`script.js`) para manipulação do DOM e interatividade do carrinho/pedidos
